# KosKita

Aplikasi manajemen kos berbasis Flask dan MySQL.

## Teknologi
- Python
- Flask
- MySQL
- HTML, CSS, JavaScript

## Instalasi

1. Clone repository.
2. Buat virtual environment.
3. Install dependency:

   pip install -r requirements.txt

4. Buat database MySQL bernama koskita.
5. Import database/koskita.sql melalui phpMyAdmin.
6. Salin .env.example menjadi .env.
7. Sesuaikan konfigurasi database.

## Menjalankan aplikasi

python app.py
